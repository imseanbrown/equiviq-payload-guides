# Equiviq Guides for Payload

Place the four SVG files from `assets/` at `/callouts/` in the host site's public directory when using the Equiviq callout style. They are the same icons used by the Equiviq Knowledge print view. The website theme style does not display icons.

Legacy published `> **NOTE**` and similar callout headings are normalized while rendering. New callouts use the `[!NOTE]` Markdown marker. Both formats render identically.
